# 副本 B / EECBS：十任务连续仿真验证与指标

本报告来自修复后从初始车位启动的一次独立 Gazebo 批次。十项任务保持原 ID、任务参数与提交顺序，未中途重启调度器、手动移车、重新命名补跑或合并旧批次。

除墙钟耗时外，时间指标均采用仿真时间。Makespan 从本批次首项任务提交算到最后一项完成；平均完成时间包含排队。总里程与能耗为项目调度器的统计及估算，能耗来自车型、载荷与里程模型，不是电表测量。空驶和已计入的让位/返航会影响车队总量；最后完成后的返航不计入 Makespan。

利用率为四台机器人的任务忙碌时间之和除以 `4 × Makespan`，不把让位、返航算作任务忙碌时间；任务内的交通等待和装卸仍计入忙碌时间，因此这里不是纯运动利用率。单次成功运行证明该场景能够执行完成，不构成最优 Makespan 或相对旧方法提升的证明。

## 方法运行证据

本次实际模式：EECBS；原生路线协调请求 54 次；临时拒绝 0 次；选择绕行候选 0 次。临时拒绝会停止当前规划并重试，不等同于任务失败。

CBS/EECBS 只对有限车身可行候选目录及离散时间模型给出代价性质；不构成全连续空间最优解、实际 Makespan 次优界限或相对 A 提升的证明。当前连续瓶颈仍需独占准入。

实际平面物理车身对静态地图的逐位姿检查：碰撞样本 0，各机器人约 58191 个采样。该检查不构成未测量的动态碰撞统计。
